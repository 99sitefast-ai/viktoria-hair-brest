# Виктория · выпрямление и восстановление волос (Брест)

Статический сайт на 7 страниц: главная, выпрямление, восстановление и уход,
наращивание и завивка, как проходит визит, обо мне, контакты. Плюс 404, sitemap, robots.

## Публикация
Сайт отдаётся через GitHub Pages из ветки `main`, папка `/`.
После правок: `git add -A && git commit -m "..." && git push`.

## Что заменить
- `assets/img/*.jpg` — фотографии. Сейчас стоят сгенерированные под тему
  (hero-hair, iron, mask, shine, studio, extensions, scalp, waves).
  Замените своими работами с теми же именами файлов — вёрстка подстроится.
  Рекомендуемый размер: 1600 px по длинной стороне, JPEG q80.
- Цены на сайте не указаны: в брифе их не было. Добавьте в `vyravnivanie.html`,
  `vosstanovlenie.html`, `narashivanie.html` (блок `.rows`) или отдельной страницей.
- Сроки носки (3–6 месяцев и т.п.) — ориентировочные, проверьте под свои составы.
- Адрес кабинета: сейчас «район ЖД и автовокзала, точный адрес по записи».
